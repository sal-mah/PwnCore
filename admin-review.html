VULNERABILITY DESCRIPTION

A flaw in the Linux kernel eBPF ring buffer memory allocation allows unprivileged local users with bpf syscall permissions to bypass verifier bounds checking. When allocating contiguous ring buffer pages via bpf_ringbuf_reserve, an integer signedness mismatch in calculating slot offsets triggers an out-of-bounds heap write into neighboring slab allocations (kmalloc-512).

This flaw allows arbitrary code execution in Ring 0, leading to immediate root privilege escalation and full container escape in Kubernetes/Docker environments with unprivileged eBPF enabled.

REPRODUCTION STEPS
  1. Deploy clean Ubuntu 22.04 LTS VM with kernel 6.5.0-generic.
  2. Enable unprivileged eBPF: sysctl kernel.unprivileged_bpf_disabled=0.
  3. Compile the attached Proof-of-Concept exploit: gcc -O2 poc.c -o exp -lbpf.
  4. Execute ./exp as standard low-privilege user nobody.
  5. Observe kernel slab corruption, credential structure rewrite, and spawned root shell /bin/sh (uid=0).
