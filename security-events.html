What counts as a security event

Defined in the SRS, Section 6.

Lockout. Login blocked after 5 failed attempts in 15 minutes (SEC-07).
Rate limit. A request limit was exceeded and answered with HTTP 429 (SEC-27).
Access denied. Repeated requests for pages or Reports the role may not open (SEC-08, SEC-11).
Invalid input and API keys. Rejected input, and revoked API keys (NFR-AUD-08).
Level shows how urgent an event is. It is not a CVSS score. Entries counts the linked audit log entries.
