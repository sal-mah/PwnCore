Heap overflow in Halcyon OS nf_tables set handling

Published with a confirmed vendor patch. Sample data.

PWN-2026-0142 · KernelPublished
■■■■Critical · CVSS 9.8 Halcyon OS 14.2 · by @nullbyte · Bug Hunter
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

An integer overflow while sizing set elements leads to an undersized kernel buffer. A later copy writes past the end of it. The Researcher showed that a crafted rule set can corrupt neighbouring kernel memory.

BUG: KASAN: slab-out-of-bounds in nft_set_elem_init+0x1a4/0x2c0
Write of size 8 at addr ffff88810a3c4f48 by task poc/2113
