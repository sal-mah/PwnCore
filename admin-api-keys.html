How keys are protected

Each rule links to a requirement in the SRS, Section 6.

Never shown. Keys are made with a secure random generator, shown to the owner once and stored only as a hash (SEC-14).
Revocable. An owner or an Admin can revoke a key. Every key has an expiry date (SEC-15).
Limited. A key never has more permissions than its owner's role (SEC-15).
Logged. Creating or revoking a key is written to the audit log (NFR-AUD-01).
Created elsewhere. Owners create keys on the Researcher API Keys page, built by Person 2. This page is the Admin view only.
