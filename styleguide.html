Colors

Black, white and one red. Use the variables, never raw hex values.

--bg#0a0a0aPage background
--surface#101010Cards, inputs, menus
--line#232323Dividers
--line-2#333333Borders on controls
--dim#5a5a5aInactive marks
--muted#8f8f8fLabels, captions
--body#b8b8b8Running text
--text#edededMain text, 2px section rules
--white#ffffffHeadings, button text
--accent#dc2229The only red

Red is for one thing per screen: the primary action, a Critical severity, the current state. If everything is red, nothing is. Write color: var(--muted) in CSS.

Type

Three fonts, each with one job.

--display · Chakra PetchHeadings and numbers
--sans · GeistBody text, buttons, menus and anything people read in sentences.
--mono · Geist MonoPWN-2026-0142 · CVSS:3.1/AV:N/AC:L · 2026-09-28

Headings are uppercase Chakra Petch. Report IDs, dates, CVSS vectors, counts and labels are mono. Everything else is Geist. No other fonts.

Motion

The motion kit does most of this for you. Just add the class. Everything switches off for people who prefer reduced motion.

Hover the buttons and nav links on this page to see the lift and underline.
<nav class="pc-nav">      red underline slides in on hover, current page marked automatically
<div class="pc-enter">    children rise in one after another when the page loads
<section data-pc-reveal>  fades in when scrolled into view
<a class="btn">           lifts 2px on hover
<!-- Pages fade into each other automatically in Chrome and Edge. Nothing to add. -->

Cursor

A dot with a label showing the request a click will make. Mouse only. Text inputs keep the normal cursor.

RegisterWeb reportsRanks →Move the mouse over these. The label follows the dot.
<a href="feed.html?category=web">Web</a>
<!-- cursor label: GET /feed?category=web  (worked out from the link) -->

<a class="btn red" href="#" data-req="POST /register">Register</a>
<!-- cursor label: POST /register  (buttons and custom elements need data-req) -->

<!-- In <head>:  css/pwncore-cursor.css      Before </body>:  js/pwncore-cursor.js (after pwncore-nav.js) -->

Links label themselves. Add data-req="METHOD /path" to buttons and custom elements. Do not set your own cursor: styles.

Rules

What keeps five people's pages looking like one site.

Use the variablesColors, fonts and spacing come from pwncore.css. If something is missing, ask Tito to add it.
Hard edgesNo rounded corners and no shadows. Borders are 1px, section rules are 2px white.
Short copyPlain words, no exclamation marks, no filler. A button says what it does.
Use the shared namesPwnCore, Researcher, Admin, Vendor, Report, User. The five ranks are Script Kiddie, Bug Hunter, Exploit Dev, Zero-Day Hunter and Red Teamer.
No new colorsNo blue links, no green success. Use white, grey and the one red.
No new fonts or iconsUse the three fonts. Marks are squares, bars and chevrons, not emoji.
Don't copy the headerEvery page uses <header id="pc-header"> and the script. Never paste header code.
Don't edit pwncore.css aloneSend changes to Tito so all pages stay in sync.
